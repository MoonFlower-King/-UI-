# 视觉与动效规范

这份规范是从已发布的 7 期（EP01–EP06、EP11）里总结出来的。它是**系列的长相**，新一期必须照着做，观众才会一眼认出“又是江月这个系列”。

## 1. 画面结构（外壳，不许改）

外壳 CSS 位于 `templates/动画网页.html` 的「外壳：所有期数共用，不要修改」与「外壳结束」之间，必须整段原样复制。`check.mjs` 会逐字比对这一段。

| 项目 | 横屏 | 竖屏（URL 带 `#portrait`） |
|---|---|---|
| 画布 `#stage` | 1600×1000，导出时放大 1.2 倍，得到 1920×1200（16:10） | 1080×1920（9:16） |
| 网格 | 3 列 × 2 行，间距 36/32 | 2 列 × 3 行，每列固定 456px，间距 56/40 |
| 标题 | 一行：给 AI 描述 **主题**，记住这 6 个词（38px） | 两行：主句 56px，副句「记住这 6 个词」40px |
| 宫格 | 白边浏览器窗 `.sandbox`，高 250px，带三个灰点的 `.browser-bar` | 同横屏，宫格内的坐标不用改 |
| 术语标签 | 英文 16px 灰（#52525B）在上，中文 22px 粗黑在下 | 英文 20px，中文 30px |
| 水印 | 右下角「江月AI设计」14px #A1A1AA | 跟在网格下方，右对齐 |
| 底色 | 页面 #F4F4F5，画布纯白 | 同左 |
| 字体 | `-apple-system, Inter, PingFang SC, Microsoft YaHei` | 同左 |

**宫格坐标系**：`.viewport` 宽约 456px、高约 224px。镜头里的元素都用 `position:absolute` 按像素摆放；横屏和竖屏共用同一套坐标。

## 2. 宫格里画什么

- **只画 UI 的“骨架”**：内容一律用灰色骨架条（`.bar` #E4E4E7、`.bar.soft` #F4F4F5）、灰色方块（#E4E4E7）和圆角卡片（白底 + 1.5px #E4E4E7 边框 + 14px 圆角）来表示。不写真实文字，不用图片，不用 emoji。
- **只有“主角”上色**：每个宫格只有被讲解的那个效果使用 `var(--accent)` 系列颜色，其余都是灰。这样观众的视线 0.5 秒内就能落到重点上。
- **上下文要能认出来**：给主角配一个真实场景的骨架，例如通讯录列表、设置页开关列表、导航栏、商品卡片。观众一看就知道“这是在 App 的哪里”。
- **鼠标指针**：hover 和 click 类的镜头都用同一个 SVG 黑箭头（白描边），用 `translate` 移动，指尖对准目标。按下 = `scale(0.85)`，`transform-origin: 4.6px 2.3px`；点击点同时泛起一圈灰色 `.click-ring`。
- **滚动类**：右侧画模拟滚动条 `.scrollbar`（外壳自带），页面层用 `translateY` 模拟滚动。
- **纯 CSS / 内联 SVG**：不引外部脚本、库或图片。动画全部用 `@keyframes`。

## 3. 配色：苹果系统色，按语义选

- **标题关键词固定用金橘色** `--accent: #FA8C16`。它是系列的标志色，不要改。
- 每个宫格的 `.viewport` 加一个 `hue-xxx` 类，把这一格的 `--accent / -strong / -light / -soft / -faint / -shadow` 整体切成该色相。
- 按**语义**选色（已发布的期数就是这样用的）：

| 色相 | 语义 | 已用过的例子 |
|---|---|---|
| `hue-blue` | 默认主操作、链接、信息 | Ripple 主按钮、Loading Button、Drawer、Glassmorphism |
| `hue-green` | 成功、开启、完成、新增 | Toggle 开启、Optimistic UI、Toast 保存成功 |
| `hue-pink` / `hue-red` | 喜欢、点赞；危险、删除、警示 | Particle Burst 爱心、Backdrop Modal |
| `hue-orange` | 需要用户注意或坚持的动作、强调 | Hold to Confirm、Morphing、Skeleton |
| `hue-purple` / `hue-indigo` | 导航、菜单、浮层、“高级感” | Hamburger、Popover、Bottom Sheet、Magnetic |
| `hue-teal` | 刷新、同步、进度 | Pull to Refresh |
| `hue-yellow` | 高光、聚光、提示 | Spotlight Border |

- 一期 6 个宫格**尽量用 4 种以上色相**，相邻宫格不要同色。讲“风格”的那类期数（比如 EP06 视觉质感）例外，每格的风格本身就是配色。
- 只用外壳里定义好的 9 种色相，不要临时写新的十六进制颜色。粒子、彩球这类装饰元素例外，也只从系统色里取。

## 4. 动效：一个 4 秒主时钟

所有动画共用 `--clock: 4s infinite cubic-bezier(0.4, 0, 0.2, 1)`。只有需要匀速的（扫光、转圈、预采样的分段滚动）才用 `--baked: 4s infinite linear`。**不要写其他时长**，否则 12 秒视频循环到第 2、3 圈时会错位。

**节拍**（6 个宫格同步，画面整齐，像一个人在依次演示）：

| 时间 | 进度 | 发生什么 |
|---|---|---|
| 0–0.6s | 0–15% | 静止，让观众先看清“原状态” |
| 0.6–1.0s | 15–25% | 触发：指针移入/按下，滚动开始，浮层弹出 |
| 1.0–2.6s | 25–65% | 效果展开，并停在“结果状态”。**2.4s（60%）就是封面帧**，这一刻每个宫格都必须是最能说明这个词的样子 |
| 2.6–4.0s | 65–100% | 平滑还原到 0% 的状态，首尾帧完全一致，循环无缝 |

- 点击类的标准指针路径：`0%,15%` 停在右下角 → `21%` 移到目标 → `23%` 按下 `scale(.85)` → `26%,65%` 停在目标上 → `100%` 回到起点。
- 动作要“有物理感”：先压缩再弹开（0.97 / 0.8 → 1.28 → 1），滑块先拉长再滑动，浮层带一点 overshoot。这正是要教给观众的“专业细节”。
- 单个宫格的动作能用一句话说清楚。如果说不清楚，这个词的演示就要简化。
